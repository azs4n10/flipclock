Flipclock — Privacy Policy

Last updated: 24 September 2026

Flipclock does not collect, store, or transmit any personal information. There are no accounts, no analytics, no advertising, and no tracking of any kind.

What the app stores

Your settings — the theme, the fonts, the display options, the signature text you type, the background sound you pick, and your Pomodoro lengths and progress — are saved only on your own device, using the platform's standard local storage. They never leave the device. They are removed when you uninstall the app, or when you clear the site data in your browser.

Network connections

The app works without an internet connection. Every typeface it offers is bundled inside the app, and the app itself never contacts a server. The installed version on a phone or tablet makes no network connections at all.

The browser version

The version that runs in a browser is hosted on GitHub Pages, so GitHub's servers keep the usual web server records, such as the IP address and the page requested. The browser version also requests one typeface, Roboto, from Google's font servers (fonts.gstatic.com), because the framework the app is built with uses it as its default. That request carries the technical information any web request carries, such as your IP address, and is handled under Google's privacy policy; nothing about you or about how you use the app is sent. See the GitHub Privacy Statement.

Children

The app is suitable for any age, and it collects nothing from anyone.

If this policy changes, the date at the top of this page changes with it.

プライバシーポリシー（日本語）

最終更新日: 2026年9月24日

Flipclock は、個人情報を収集も保存も送信もしません。アカウントも、 利用状況の計測も、広告も、追跡も一切ありません。

アプリが保存するもの

配色、フォント、表示の設定、入力した署名の文字、選んだ背景音、ポモドーロの 長さと進み具合といった設定は、お使いの端末の中だけに、各プラットフォームの 標準的なローカル保存領域を使って保存されます。端末の外に出ることはありません。 アプリを削除したとき、またはブラウザのサイトデータを消したときに一緒に消えます。

通信について

このアプリはインターネットに接続しなくても動きます。選べる書体はすべて アプリの中に同梱しており、アプリ自身がサーバーへ接続することはありません。 携帯電話やタブレットに導入した版は、通信を一切行いません。

ブラウザ版について

ブラウザで動く版は GitHub Pages で公開しているため、GitHub のサーバーには IP アドレスや要求されたページといった、一般的なウェブサーバーの記録が残ります。 また、ブラウザ版では Roboto という書体を Google の書体配信サーバー （fonts.gstatic.com）から取得します。アプリを作っている枠組みが既定の書体として 使うためです。この通信には一般的なウェブの通信と同じく IP アドレスなどの技術的な 情報が伴い、その取り扱いは Google のプライバシーポリシーに 従います。利用者ご自身や使い方に関する情報を送ることはありません。 詳しくは GitHub のプライバシーに関する声明をご覧ください。

お子さまの利用について

年齢を問わずお使いいただけます。誰からも情報を収集しません。
